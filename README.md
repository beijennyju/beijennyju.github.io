# Bei Ju — Academic website

This repository publishes the academic website of Dr Bei (Jenny) Ju at <https://beijennyju.github.io>.

The GitHub Pages version remains static. The repository also includes an EdgeOne Makers function for Bei AI, powered by the free DeepSeek edge model. No API keys are stored in this repository.

To enable Bei AI, connect this repository to an EdgeOne Makers project. The function at `edge-functions/api/chat.js` is then deployed as `/api/chat` on the EdgeOne domain.
